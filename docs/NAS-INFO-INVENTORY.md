# CCMB 2.0.33 원본 화면과 NAS 데이터 대조표

기준은 사용자 지정 **v2.0.33 태그**(ae2f4d9e373ee99dada2bd9734cf57d707bb22a3, 2026-10-04 공개)다. 2026-10-16 이전 복원에서 v2.0.34를 기준으로 삼은 판단은 잘못이었으며 이 문서가 대체한다. 특히 2.0.33에는 Gemini 온라인 정보가 있었으므로 NAS에서 수집하지 않는다는 이유로 항목을 없애면 원복이 아니다.

색·폰트·간격·원형 게이지·행 그룹·차트·버튼·테마·투명도 구조는 태그의 기존 렌더러를 사용한다. 현재 선택된 Gemini 계정 한 카드만 표시하고 주/부 표기만 유지한다. 전체 계정·실행 호스트·자동 전환 진단은 NAS 서버 현황에서 다룬다. 기존 사용자 설정과 로그인은 보존한다.

NAS 미수집 온라인 값은 0% 또는 100%로 꾸미지 않는다. 예전 Mac 온라인 캐시·Mac발 릴레이·다른 계정 캐시·로컬 로그인·상품명 추정으로 메우지 않는다. NAS 모드의 온라인 항목에서 Mac 로그인은 시작하지 않는다. 온라인 로그인 동작은 데이터 수집 위치 변경에 따라 원본과 동일하게 실행할 수 없는 예외이며 사용자에게 알린다.

## 현재 NAS에서 가져올 수 없는 원래 정보

1. Gemini 온라인 세션/주간 남은 한도와 각 초기화 시각. NAS에는 현재 이를 직접 수집하는 경로가 없다. 남아 있는 `CCMB-gemini-online-v1.json`은 과거 Mac에서 보낸 자료여서 최신 NAS 수치로 사용하지 않는다.
2. Gemini 구독 상품명. CLI 한도나 사용자 구독 설명으로 상품명을 생성하지 않는다.
3. NAS 응답에 포함되지 않은 제공사 계정 표시 정보. 인증 파일이나 Mac 로그인에서 가져오지 않으며, NAS의 고정 계정 참조를 이메일로 둔갑시키지 않는다.

일시 수집 오류는 미지원 항목과 구분한다. 마지막 정상 수치는 보존하되 오류/오래됨을 표시하며 NAS 장애를 Mac 직접 조회로 대체하지 않는다.

- Gemini AI크레딧: 공식 `/credits` 읽기와 계정 검증. 두 계정 모두 0 확인. CLI 한도/온라인 한도와 별개.
- 계정 전환 이유·본계정 복귀 상태·수집 시각·다음 조회·오류와 재시도 대기. NAS 서버 현황에서 확인 가능.

## 갱신 계약 유지

이 복원은 최근 승인된 갱신 수정과 계정 전환을 되돌리지 않는다. NAS 공유 스케줄러는 유휴 300초, 실제 작업/의미 있는 변화 시 30초 예약이다. 실제 새 수치 간격에는 CLI 수집 시간이 더해진다. 서비스별 Retry-After가 우선하고 정상 서비스는 계속 수집한다. 사용량 0 구간의 이동하는 초기화 시각과 초 단위 시간 흔들림을 활동으로 오인하지 않는다. Mac/iPhone 기존 수동/스마트 설정을 임의 변경하지 않는다.

2026-10-16 검증: 실제 NAS 응답의 production 모델 대조에서 Codex 4행, Claude 기본 4행+추가 사용량, Gemini 4게이지+요금제/4초기화 행 및 각 계정 위치를 확인했다. ## 2026-10-16 18:18 사용자 조정 — 현재 화면 기준

이후 직접 지시가 위 v2.0.33 원복의 해당 부분을 대체한다. Mac 2.1.7부터 Claude 추가 사용량 영역을 표시하지 않는다. Gemini의 네 게이지는 왼쪽 본계정 세션/주간, 오른쪽 보조계정 세션/주간이며 모두 C/O 접두어 없이 표시한다. 초기화 행과 계정 푸터는 본/보조 구분을 유지한다. 온라인 한도는 이 네 게이지에 사용하지 않는다. NAS의 account_display를 실제 제공사 계정 표시로 사용하며 Mac 로컬 인증에서 보충하지 않는다.

열정 그래프는 NAS가 기록한 회차별 소비량을 그대로 표시한다. Gemini 본/보조 이력은 각 계정의 신원 세대가 일치하는 데이터만 별도 시리즈로 사용하며 Mac에서 소비량을 다시 계산하지 않는다. NAS 스냅샷과 이력은 3분 간격으로 읽고 수동 새로 고침은 즉시 읽는다. 서버 유휴 수집도 3분으로 맞추며 활동 시 빠른 수집과 요청 제한 보호는 유지한다.

사용자 지시에 따라 이 수정은 테스트·별도 검토·화면 검증 없이 빌드 후 즉시 Mac 교체 설치·재실행했다. 앞 절의 테스트 통과 기록은 2.1.6에 관한 기록이며 이 수정에 확대하지 않는다. 이후 테스트가 필요하면 가능한 범위에서 Gemini를 우선 사용한다.


### 2.1.8 갱신·명칭 조정

NAS 모드 Codex·Claude·Gemini의 실제 조회 주기·메뉴 선택·카운트다운을180초로 통일했다. NAS모드 간격선택으로 로컬 수집 설정을 덮어쓰지 않는다. 사용자 표시 명칭은‘부계정’으로 통일하며 부계정ID는NAS account_display를 사용한다. NAS 저장스냅샷 진단에서 본계정·부계정 이메일의 정상 전달과 Claude 요청제한이 없는 정상 응답을 확인했다. 별도 앱 렌더/테스트는 실행하지 않고 2.1.8을 빌드 직후 설치·재실행했다.

CLI복구는 전역 실행파일/본계정로그인 변경 없이, 기존 등록된 SHA와 같은1.3.6을 관리용 경로에 보존하고 native/부계정폴더의CLI링크로 사용한다. 공식CLI 갱신은 부계정 격리폴더에서 수행하며 본계정 인증 경로는 기존 제한으로 차단한다.

### 2.1.9–2.1.10 표시 수정 (2026-10-16)

Gemini 제목은 `Gemini`만 표시한다. 계정 정보는 NAS 원본 신원을 유지하되 Gmail 주소에 한해 표시 문자열에서 `@gmail.com`을 생략한다. 부계정 정보가 줄바꿈될 때 필요한 실제 텍스트 높이를 확보한다. 본/부 요금제 행은 `gemini_details.plan_title`의 실제 수집 값을 각각 표시하며, 결측을 한도 구간이나 사용자 진술로 추정해서 채우지 않는다.

Claude NAS 오류가 RetryAfter를 포함하면 실제 다음 조회 시각을 표시한다. NAS의 Claude 제공사 조회는 다른 작업의 활성 힌트와 관계없이 180초 하한을 유지한다. 이는 429를 표시에서 숨기는 변경이 아니며 제공사 제한 시 기존 backoff를 계속 존중한다.

2.1.9 빌드·서명·설치·재실행 후 추가 직접 요청인 Gmail 도메인 생략을 2.1.10에 반영해 즉시 다시 빌드·서명·설치·재실행했다. 테스트·별도 검토·화면 대조는 사용자 지시에 따라 실행하지 않았다. 요금제 실수집과 Gemini 실행 전 갱신 차단의 서버 변경은 별도 작업 기록으로 완료 여부를 구분한다.

### 2.1.11 Claude 초기화권 표시 복원

추가 직접 요청에 따라 Claude 카드에 초기화권 개수·사용 가능 상태와 만료일을 다시 표시한다. `ClaudeUsageSnapshot.limitResets`는 NAS `claude_details.limit_resets`를 그대로 사용한다. 2026-10-16 19:32 KST 저장 원본은 `remaining_count=1`, `usable_now=true`, `expires_at=1792684800`이었다. 초기화 실행 버튼이나 소비 API는 추가하지 않는다. Claude 추가 사용량 영역을 숨기는 기존 요청은 유지한다.

### 2.1.12 초기화권 문구·만료시간

Claude 초기화권 행은 개수만 표시하고 만료시간 상세는 유지한다. Codex는 NAS `codex_details.reset_credit_expirations`의 실제 사용 가능한 권별 만료시간을 정렬해 개수 아래 각각 표시한다. 만료 자료가 전혀 없으면 개수를 지우지 않고 만료 정보 없음을 표시한다. 원본 신원·로그인·초기화권 소비 동작은 변경하지 않는다. 테스트·별도 화면 검증은 수행하지 않는다.

### 2.1.13 만료시간 압축 표시

Codex 초기화권 만료시간은 개별 표 행을 제거하고 `초기화 가능 N개` 아래 기존 상세 글꼴 10pt로 모아 표시한다. 만료시간끼리는 구분선·문단 여백 없이 12pt 높이로 연속 배치한다. 기존 한 줄 상세(Claude 만료시간 포함)의 크기는 유지하며 여러 줄 상세에만 필요한 높이를 더한다. NAS 수집·인증·데이터 구조는 변경하지 않는다.

### 2.1.14 목록 잘림·정렬 후속 수정

실제 맥 캐시에 Codex 만료시각 세 개가 있음을 확인했다. 여러 줄 상세의 고정 행 높이·문단 여백 0을 명시하고 텍스트 셀에 필요한 여유 높이를 추가한다. 초기화권 만료 목록만 오른쪽 정렬하며 기존 다른 상세의 정렬은 유지한다. Gemini 부 요금제 행은 직접 요청에 따라 숨긴다. 부계정 한도·신원·NAS 요금제 수집은 보존한다. 별도 테스트·화면 대조 없이 빌드·교체 설치·재실행한다.

### 2.1.15 초기화 명칭 통일

Codex와 Claude 카드의 초기화권 개수 행은 모두 `초기화`로 통일한다. 두 카드의 만료시간 상세는 같은 오른쪽 끝에 맞춘다. 2.1.14의 세 줄 잘림 보정과 Gemini 부 요금제 행 제거를 포함한다. 데이터 수집·인증은 변경하지 않는다.
