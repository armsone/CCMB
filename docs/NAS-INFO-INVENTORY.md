## 새로 요청한 Claude 리셋권

실제 NAS usage/profile 응답에는 리셋권 개수 필드가 없었다. 공식 안내는 웹/데스크톱 Usage 화면의 리셋 기능을 설명한다. **현재 NAS 수집 경로는 미확보**이며 0개로 표시하지 않는다. 한두 조회 응답에 필드가 없다고 모든 API에서 불가능하다고 단정하지 않는다. 리셋권을 자동 소비하는 기능은 구현하지 않는다.

## 기존 카드와 별도로 다룰 정보

Claude 모델명·컨텍스트·작업 비용은 statusLine/공유 데이터 모델에 존재하지만 v2.0.34 claudeColumn의 실제 카드 행에는 사용되지 않았다. 모델에 필드가 있다는 이유로 화면 회귀라고 단정하지 않는다. NAS 작업의 해당 정보를 추가하려면 NAS statusLine 출처와 작업 ID 대응이 필요하며 Mac 작업 정보를 NAS 작업처럼 보이지 않는다.

Gemini 온라인 웹 한도·AI 크레딧은 v2.0.34의 CLI 공유 데이터와 별도 브라우저 경로에 있으며 원래 세 카드의 표시 항목과 구분한다. NAS에 없는 Mac 브라우저 세션 데이터를 자동 전송하지 않는다.

## 현재 계정 선택과 향후 여러 계정

현재 v2 account1/account2는 호환 계약이다. NAS 모드의 Gemini 카드는 host_id=nas인 실행 범위 하나만 따른다. Mac 호스트 이벤트가 NAS 카드 계정을 바꾸지 않는다. 자동 전환이 꺼졌거나 상태가 미확인이면 기본 본계정을 표시하며, 이 기본값을 실제 실행 중이라는 주장으로 사용하지 않는다. return_state=confirmed는 본계정 복귀 확인이다. idle에서 마지막 선택 계정을 보존하는 v3 명시 필드는 아직 미구현이다.

여러 보조계정·향후 Claude 계정은 제공사별 본계정과 동적 accounts[] 목록으로 확장하는 별도 v3 설계를 따른다. 카드 개수는 세 개를 유지하고 전체 계정 현황은 NAS에서 다룬다. 새 폴더 방식 인증과 자동 전환은 아직 운영 활성화되지 않았다.
