# CCMB 원래 정보 구성과 NAS 데이터 계약

기준: 기존 안정판 v2.0.34의 세 카드, 2026-10-16 사용자 최종 요청. 현재 복원본 Mac2.1.5 / iOS 갱신 수정0.3.2 / NAS0.22.3. 본 문서는 이전의 누적 보고와 초기화권0개 오판을 대체하는 현행 표시 계약이다.

## 기본 화면

| 카드 | 유지할 원래 정보 |
| --- | --- |
| Codex | 주간 남음, 요금제, 주간 초기화, 초기화 가능 횟수, 남은 크레딧 |
| Claude | 세션·Fable·주간 남음, 요금제, 각각 초기화 시각, 기존 모델별 한도와 추가 사용량 |
| Gemini | 현재 선택된 계정 한 장, 세션·주간 남음과 초기화 시각, 실제 상품명 원본이 있을 때만 기존 요금제 행 |

세 카드의 기존 색·글꼴·게이지·행·차트·버튼은 유지한다. NAS라는 이유로 정보 종류를 재설계하지 않는다. 기본 화면에서 새 Gemini AI크레딧, 확인 불가 요금제 강제 행, Claude 리셋권 행, 반복 NAS 기준/호스트 진단 안내는 제거했다. 원래 항목인 Codex 초기화 가능 횟수는 유지한다. 실제 수집 실패·소진은 숨기지 않으며 마지막 정상 수치와 짧은 상태를 유지한다.

기존 전체 계정 목록은 NAS 서버 현황에서 확인한다. Mac은 선택된 Gemini 계정 한 장만 표시한다. 실제 로그인 계정을 다른 계정의 캐시로 채우거나 알 수 없는 상품명을 추정하지 않는다. 최신 직접 요청에 따라 신규 정보는 기본 카드에 임의로 추가하지 않는다.

## 추가 표시 가능한 정보 (현재는 기본 카드에 추가하지 않음)

- Claude 초기화권: NAS의 기존 OAuth 읽기 GET과 설치 공식 CLI 식별값으로 권수·즉시 사용 가능 여부·만료 시각을 수집한다. 실제1회, 사용 가능, 2026-10-23 01:00 KST를 확인했다. 소비 동작은 없다.
- Gemini AI크레딧: 공식 `/credits` 읽기와 계정 일치 검증을 사용한다. 현재 두 계정 모두0으로 확인했으며 세션/주간 한도 및 자동 전환 조건과 별개다.
- 계정 전환 상태: 현재 계정, 전환 이유, 본계정 복귀 여부와 시각. NAS 서버 현황의 기존 계약에서 확인 가능하다.
- 수집 상세: 서비스별 수집 시각·오류·다음 조회 예정, 유휴/작업/요청 제한 대기.
- Gemini 구독 상품명·온라인 한도는 현재 신뢰할 조회 출처가 미확보여서 표시 가능 정보로 확정하지 않는다.

## 갱신 계약

조회 화면 자체와 경과 시각은 활동으로 보지 않는다. 미사용 구간의 이동하는 초기화 시각은 활동 지문에서 제외하고 사용 구간의 초기화 시각은 최근접 분으로 비교한다. 원본 표시 시각은 그대로다. 계정·세대·실제 수치·초기화권 변화는 감지한다. 선택적 조회의 일시 실패를 소비량 변화로 만들지 않는다.

NAS 공유 스케줄러는 유휴300초, 실제 작업/의미 변화 시30초 예약을 사용한다. 동시 수집을 겹치지 않으므로 실제 새 수치 간격에는 CLI 조회 시간이 추가된다. Python 서비스 캐시는 유휴180초/활성30초이며 HTTP·SSH의 전체 정책은 실제 Node 스케줄을 따른다. Retry-After는 서비스별 우선하며 건강한 다른 서비스는 계속 갱신한다. 5분 유휴 끝의 정상 수집 지연을 즉시 오래됨으로 오판하지 않도록 신선도에는1분 여유를 둔다. 실제 수집 오류·실패는 즉시 구분한다.

Mac/iPhone도 같은 시간 흔들림을 활동으로 오인하지 않도록 수정했다. 기존 사용자 설정과 로그인은 보존하며 iOS는 foreground에서만 갱신한다.

## 확인 범위

Mac2.1.5 빌드·서명·공증·공개·데이터 유지 교체 설치·재실행, 공개 DMG 해시와 Sparkle 서명을 확인했다. iPhone0.3.2 빌드·설치·실행 및 설치 버전을 확인했다. NAS 초기화권1회의 실제 수집과 설치된 Mac의 안전 캐시 전달을 확인했다. 실제 확인용75초 작업을 사용해 유휴→활성→유휴 정책과 수집 시계열을 관찰했으며 사용자 원본은 수정하지 않았다. 확인용 대화는 목록에서 정리하고 서버 기록은 보존했다.

Mac 기본뷰 소스와 정보 구성을 기준판에 대조했지만 네이티브 화면 캡처 도구가 timeout되어 설치 창 전체의 픽셀 대조는 미확인이다. 합성 렌더나 캐시 수신을 실제 창 스크린샷으로 주장하지 않는다.
