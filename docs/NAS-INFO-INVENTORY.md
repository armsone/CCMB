# CCMB 2.0.33 원본 화면과 NAS 데이터 대조표

기준은 사용자 지정 **v2.0.33 태그**(ae2f4d9e373ee99dada2bd9734cf57d707bb22a3, 2026-10-04 공개)다. 2026-10-16 이전 복원에서 v2.0.34를 기준으로 삼은 판단은 잘못이었으며 이 문서가 대체한다. 특히 2.0.33에는 Gemini 온라인 정보가 있었으므로 NAS에서 수집하지 않는다는 이유로 항목을 없애면 원복이 아니다.

## 기본 화면 계약

| 카드 | 2.0.33의 게이지·행·푸터 | NAS 제공 범위 / 부족한 값 처리 |
|---|---|---|
| Codex | 주간 남음; 요금제·주간 초기화·초기화 가능·남은 크레딧; 계정·갱신 시각 | 네 수치 행은 실제 NAS 값으로 유지. NAS에 계정 표시 정보가 없으면 기존 계정 위치에 정보 없음 표시 |

색·폰트·간격·원형 게이지·행 그룹·차트·버튼·테마·투명도 구조는 태그의 기존 렌더러를 사용한다. 현재 선택된 Gemini 계정 한 카드만 표시하고 주/부 표기만 유지한다. 전체 계정·실행 호스트·자동 전환 진단은 NAS 서버 현황에서 다룬다. 기존 사용자 설정과 로그인은 보존한다.

NAS 미수집 온라인 값은 0% 또는 100%로 꾸미지 않는다. 예전 Mac 온라인 캐시·Mac발 릴레이·다른 계정 캐시·로컬 로그인·상품명 추정으로 메우지 않는다. NAS 모드의 온라인 항목에서 Mac 로그인은 시작하지 않는다. 온라인 로그인 동작은 데이터 수집 위치 변경에 따라 원본과 동일하게 실행할 수 없는 예외이며 사용자에게 알린다.

## 현재 NAS에서 가져올 수 없는 원래 정보

1. Gemini 온라인 세션/주간 남은 한도와 각 초기화 시각. NAS에는 현재 이를 직접 수집하는 경로가 없다. 남아 있는 `CCMB-gemini-online-v1.json`은 과거 Mac에서 보낸 자료여서 최신 NAS 수치로 사용하지 않는다.
2. Gemini 구독 상품명. CLI 한도나 사용자 구독 설명으로 상품명을 생성하지 않는다.
3. NAS 응답에 포함되지 않은 제공사 계정 표시 정보. 인증 파일이나 Mac 로그인에서 가져오지 않으며, NAS의 고정 계정 참조를 이메일로 둔갑시키지 않는다.

일시 수집 오류는 미지원 항목과 구분한다. 마지막 정상 수치는 보존하되 오류/오래됨을 표시하며 NAS 장애를 Mac 직접 조회로 대체하지 않는다.

## 추가로 보여줄 수 있지만 기본 화면에 넣지 않는 정보

- Claude 초기화권: 기존 NAS OAuth의 읽기 GET과 설치 공식 CLI 식별값으로 수집. 2026-10-16 실제 1회·사용 가능·2026-10-23 01:00 KST 만료 확인. 소비 동작 없음.
- Gemini AI크레딧: 공식 `/credits` 읽기와 계정 검증. 두 계정 모두 0 확인. CLI 한도/온라인 한도와 별개.
- 계정 전환 이유·본계정 복귀 상태·수집 시각·다음 조회·오류와 재시도 대기. NAS 서버 현황에서 확인 가능.

## 갱신 계약 유지

이 복원은 최근 승인된 갱신 수정과 계정 전환을 되돌리지 않는다. NAS 공유 스케줄러는 유휴 300초, 실제 작업/의미 있는 변화 시 30초 예약이다. 실제 새 수치 간격에는 CLI 수집 시간이 더해진다. 서비스별 Retry-After가 우선하고 정상 서비스는 계속 수집한다. 사용량 0 구간의 이동하는 초기화 시각과 초 단위 시간 흔들림을 활동으로 오인하지 않는다. Mac/iPhone 기존 수동/스마트 설정을 임의 변경하지 않는다.

## 검증 기록

이번 복원은 태그 소스의 정보 목록 대조, 실제 NAS 스냅샷을 production `makePanelModel()`과 기존 AppKit 뷰로 전달한 렌더, 빌드·서명·공증·교체 설치 결과로 확인한다. 네이티브 앱 화면 자동 캡처는 도구 시간 초과로 불가하여 렌더 증거와 설치 창 스크린샷을 구분한다. 최종 버전·해시·대조 결과는 릴리스 결과 기록에 남긴다.

2026-10-16 검증: 실제 NAS 응답의 production 모델 대조에서 Codex 4행, Claude 기본 4행+추가 사용량, Gemini 4게이지+요금제/4초기화 행 및 각 계정 위치를 확인했다.
